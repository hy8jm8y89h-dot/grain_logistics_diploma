# Аналитическая система оценки зерновых маршрутов

Прототип программной системы поддержки принятия решений для оценки конкурентоспособности маршрутов перевозки зерна с участием речного транспорта.

## Основные функции

- выбор региона отправления и морского порта назначения;
- сравнение альтернативных схем доставки зерна;
- расчет оптимального маршрута по критерию минимальной стоимости;
- сценарный анализ изменения железнодорожных, автомобильных и речных тарифов;
- оценка внешних рыночных факторов и индекса риска;
- учет рыночного риска в тарифном сценарии;
- прогноз перевозок зерна речным транспортом до 2035 года;
- оценка загрузки речных зерновых терминалов;
- формирование итогового аналитического отчета.
